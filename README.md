# Global Green Energy Report

The Global Green Energy Report is a single-page technical report that presents information about renewable energy sources and global sustainability efforts.

## Project Overview
This repository highlights sustainable energy sources, globaladoption rates, challanges and future opportunities for cleaner energy production.

## Visual Identity
The Global Green Energy Report uses a clean ans modern design that reflects sustainability and environmental awareness.

* **Typography:** 

    - Clear and readabe fonts
    - Professional heading hierarchy
    - Consistent text spacing
* **Layout Style:**    
    - Single-page structured layout
    - Organised report sections
    - Easy navigation links
    - Accessible table format

## Current Features 
    * Semantic HTML structure
    * Header section
    * Navigation links for easy access
    * Main content area
    * Article section for renewable energy topics
    * Data table
    * Footer section
    * Organised single-page technical layout
